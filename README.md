# English & Polish Lab — educational web project

An educational website with quizzes, mini-games and language-learning content built as a browser-based project.

## My role

This project began as a simple website and was expanded with the help of AI coding tools. I worked on the project by defining features, testing generated changes, manually adjusting parts of the HTML/CSS/JavaScript and iterating on the interface and mini-games.

I present it as an **AI-assisted web project**. It is not meant to prove advanced frontend engineering; its value in my portfolio is showing practical iteration on a real, published website.

## What is included

- educational pages and language-learning content;
- quizzes and browser mini-games;
- multiple game modes and interactive exercises;
- custom HTML/CSS/JavaScript;
- static-site deployment through GitHub Pages.

## Technologies

`HTML` · `CSS` · `JavaScript` · `GitHub Pages` · browser DevTools · AI coding tools

## Portfolio value

This was one of my earlier projects and helped me learn how to change an existing interface, test browser behaviour, identify UI issues and progressively improve a working site instead of only creating isolated examples.
